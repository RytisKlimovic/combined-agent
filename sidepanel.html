Settings

Model server

Any OpenAI-compatible endpoint: a local server (vLLM, llama.cpp, Ollama, LM Studio) or a hosted provider. Paste either the server root — the /v1/chat/completions path is appended — or the full chat-completions URL if the provider puts it somewhere else.

This endpoint is not on this machine. Page text, screenshots and documents you ask about will be sent to it. Do not point it at a third-party service when working with real patient data.
Not tested yet.

Dictation server

Speech-to-text, used only by dictation. Everything else works without it.

Answers

A scanned document is read page by page — each page is a separate request to the model. The limit guards against accidentally opening a 200-page file.

Agent mode

With this on, the assistant can read a linked document itself, inspect the form fields and propose text for them (only the clinician actually writes anything). With it off, it falls back to plain chat with no tools.

Host application forms

Host applications often open a document form in a separate popup window, where this side panel does not work. With this on, the form opens as a tab in the same window and the panel works immediately. The tab can still be dragged out into its own window if needed — the panel works there too.

Usage metrics

Only numbers are collected: how many drafts were generated, how long they took, what percentage of the text you edited, how many errors occurred. No patient text is collected — not drafts, not transcripts, not questions. The data stays on this machine until you export it.
